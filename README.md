# SOLID: практика рефакторинга

В проекте три модуля с работающим, но плохо спроектированным кодом. Ваша задача — отрефакторить каждый модуль так, чтобы он соответствовал принципам SOLID, **не меняя поведения программы**.

| Модуль | Что делает                                    | Основные принципы |
|---|-----------------------------------------------|-------------------|
| `level-1-grades` | Ведомость успеваемости из CSV                 | SRP, OCP          |
| `level-2-shop` | Расчёт покупки: скидки, доставка, уведомления | OCP, LSP, ISP     |
| `level-3-orders` | Оформление и отмена заказов                   | Все пять          |

Задание к каждому модулю лежит в его папке в файле `TASK.md`.
