# Уровень 1. Ведомость успеваемости

Класс `GradeReport` читает CSV-файл с оценками студентов и формирует ведомость в текстовом или HTML-формате.
Пример данных лежит в `data/grades.csv`, в нём есть строки с ошибками.

## Задание

1. Разделите код так, чтобы у каждого класса была одна причина для изменения.
2. Сделайте так, чтобы новый формат отчёта можно было добавить, **не изменяя** существующие классы.
3. Замените вызовы `System.out.println` на вызовы логгера 

Публичный метод `GradeReport.generate(Path, Path, String)` должен остаться. Внутри он может просто собирать и вызывать новые классы.

## Расширение (после рефакторинга)
